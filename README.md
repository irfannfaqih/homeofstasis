# Stasis Marketplace Promo Portal — Wireframe

Prototipe grayscale tanpa dependency untuk memvalidasi customer journey Public Portal sebelum desain final dan implementasi Next.js/Supabase.

## Menjalankan wireframe

Jika Python tersedia:

```bash
python3 -m http.server 4173
```

Kemudian buka `http://localhost:4173`.

- Public Portal: `http://localhost:4173/index.html`
- Login Admin: `http://localhost:4173/admin.html`
- Editor CMS: `http://localhost:4173/cms.html`

## Interaksi yang tersedia

- Hero carousel otomatis setiap 5 detik.
- Tombol previous/next, indikator slide, dan swipe pada hero.
- Hero dengan link opsional.
- Navigasi marketplace menuju section terkait.
- Search marketplace dan promo.
- Sidebar yang muncul melalui toggle.
- Seluruh kartu promo dapat diklik.

Wireframe ini belum menggunakan aset, warna brand, backend, atau konten final.
